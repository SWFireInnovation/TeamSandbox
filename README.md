# Team Best Practices Sandbox

This is a git repository for groups working as part of the Southwest Fire Innovation Landscape Network to practice using git for collaborative science 
research and to document best practices for using git.

The best way to learn is by doing, so here we aim to provide a place to practice as well as demonstrate. Put whatever code you like in here. It is ok 
to break things, that just gives the community an opportunity to practice using git and documentation to restore what was broken.

## Things to Avoid
This is a public repository, so DO NOT put any SENSITIVE information here for everyone to see. There are obvious things to avoid like usernames and passwords.
However, one of the most common mistakes is including a filepath in your documents folder (exp: C:\Users\<username>\Documents). Oops, now you've shared your 
username! Similarly bad, do not include any filepaths with a server name in them.

Outside of that, git tracks your mistakes as well as your success. For a lot of people, their instict is to try erase their mistakes, but thats just not how 
git works, history is permanent. So when using git, mistakes are just a chance to show that you fixed a problem.
